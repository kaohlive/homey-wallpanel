# Enclosures

3D models for mounting a panel on a wall. Nothing here yet — the first one is a back plate
for the CrowPanel 2.1" with room for a USB-C cable turned downwards.

Print files go in a folder per board (`crowpanel21/`), as both STEP and STL: STEP so someone
can change it, STL so someone can print it without a CAD package.
