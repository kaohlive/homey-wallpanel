Flash a Homey wall panel

Plug the panel into this computer with the cable that came with it and press Install. It takes about a minute, and it is the only time a panel ever needs a cable — after this, updates come from Homey over Wi-Fi.

Elecrow CrowPanel 2.1" rotary

ESP32-S3 · 480×480 round touchscreen with a knob · board id crowpanel21
This browser cannot talk to USB devices. Use Chrome or Edge on a computer — phones and tablets cannot do this. Flashing needs a secure connection (https).

Panel stays dark after flashing? Press Install again and choose Logs & Console instead — that opens a serial monitor on the panel, right here. Press the reset button on its back and it will say what it is doing. That text in an issue is worth more than any description of a black screen.

    Earlier versions

      A panel that is already running gets these from Homey, on its device page. This page is only for a panel that has never been flashed.

      Then what?

      1. Do this first: install Wear OS Controller on your Homey — the test version, which is the one that signs what it sends a panel. This firmware refuses anything else, so a panel pointed at an older app shows nothing at all. It is also where a panel gets its cards, and where the pairing code below comes from.
      2. The panel restarts and shows Wi-Fi setup, with a network name and an eight-digit password on screen.
      3. Join that network with a phone. The setup page opens by itself; otherwise go to 192.168.4.1.
      4. Pick your network, type its password, and paste the pairing code from Homey (Wear OS Controller → app settings → Copy pairing code).
      5. Add the panel as a device in Homey, then open Repair on it to choose the cards it shows.

      Nothing here is sent anywhere: the image is downloaded from this page and written to the board by your browser. The panel never learns your Wi-Fi password from Homey — you type it into the panel itself.
